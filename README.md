# Flights Data Pipeline

Simple data pipeline that ingests flight data from API, stores raw JSON, and logs execution.

## Current Features

- API ingestion
- Raw JSON storage
- Structured Data Lake folders
- Azure Blob Storage upload
- Logging system
- Environment variables support

## Planned Improvements

- Implement Bronze → Silver → Gold architecture
- Add structured data validation and cleansing processes
- Build dimensional modeling layer using dbt
- Orchestrate pipeline workflows with Apache Airflow
- Add automated monitoring and logging
- Improve scalability and cloud integration
